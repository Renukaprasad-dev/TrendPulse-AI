# Dashboard Screenshots

Place dashboard screenshots in this directory for the README gallery.

## Expected Files

| Filename               | Description                                    |
| ---------------------- | ---------------------------------------------- |
| `overview.png`         | Executive Overview dashboard                   |
| `anomaly-detection.png`| Anomaly Detection audit log with filters       |
| `trend-analysis.png`   | Trend & Time-Series charts                     |
| `insights.png`         | Actionable Intelligence cards                  |
| `data-explorer.png`    | Raw Data Explorer table                        |
| `model-performance.png`| Model Architecture & Statistical Telemetry     |
| `ml-simulator.png`     | Real-time ML Simulator                         |
| `settings.png`         | System Settings panel                          |

## How to Capture

1. Open the live application at https://trendpulse-anomaly-analytics.vercel.app
2. Log in and navigate to each section.
3. Take a full-width browser screenshot (recommended: 1920×1080).
4. Save each screenshot to this directory with the filenames listed above.
5. Commit and push to update the README gallery.
